whytop

Live terminal UI for troubleshooting Linux servers — as an apt repository.

Install

One block, copy and paste. It fetches the signing key into its own keyring and adds the repository bound to that key alone.

sudo install -d -m 0755 /usr/share/keyrings
curl -fsSL https://archesterr.github.io/whytop/whytop-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/whytop-archive-keyring.gpg > /dev/null

sudo tee /etc/apt/sources.list.d/whytop.sources > /dev/null <<'EOF'
Types: deb
URIs: https://archesterr.github.io/whytop
Suites: stable
Components: main
Signed-By: /usr/share/keyrings/whytop-archive-keyring.gpg
EOF

sudo apt update
sudo apt install whytop

Signed-By matters: without it, this key could sign packages for any repository on the machine. Bound this way it can only ever vouch for whytop.

Verify the key first

Reasonable thing to do before trusting a repository. The fingerprint should be:

__FINGERPRINT__

curl -fsSL https://archesterr.github.io/whytop/whytop.asc | gpg --show-keys

Updates

apt upgrade, like anything else. The packaged binary has its own update check removed at build time, so it makes no network connection of its own — apt owns updates for this copy.

Architectures

amd64 and arm64. Debian, Ubuntu and derivatives; whytop needs no libraries beyond libc.

Uninstall

sudo apt remove whytop
sudo rm /etc/apt/sources.list.d/whytop.sources \
        /usr/share/keyrings/whytop-archive-keyring.gpg
